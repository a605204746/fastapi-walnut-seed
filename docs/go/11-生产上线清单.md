# 生产上线清单

> 更新日期：2026-11-04 · 适用版本：WalnutSeed v1.0

本清单适用于 Go 编排，完整部署流程见 [Docker 部署](./10-Docker部署.md)。

## 0. 启动门禁（不满足直接起不来）

| 门禁 | 触发条件 | 解除方式 |
|---|---|---|
| compose 变量强制 | `docker/.env` 未设置 `JWT_SECRET_KEY` | 设置密钥 |
| SECRET_KEY 校验 | prod 下为空 / 含 `change-me` / <32 字节 | 用随机值 |
| RSA 密钥黑名单 | prod 配置了 RuoYi 生态公开密钥 | 重新生成 |
| 路由认证审计 | 白名单外路由漏挂认证中间件 | 补 `b.Protected` 挂载 |
| 迁移 | entrypoint `set -e`，迁移失败即退出 | 修迁移文件 |
| 雪花机器位 | `SNOWFLAKE_WORKER_ID` 越界（非 0–1023） | 配置合法值 |

## 1. 密钥与账号（必改）

- [ ] **`JWT_SECRET_KEY`**：`openssl rand -hex 32` 生成，写入 `docker/.env`
- [ ] **初始账号改密**：种子数据包含 `admin / admin123`，登录后立即改密
- [ ] **`DB_PASSWORD`**：按需修改（MySQL 密码首次初始化后不随改值更新，需 `ALTER USER`）
- [ ] **接口加解密 RSA 密钥**：生产生成新密钥对，分别配前后端
- [ ] **SeaweedFS 凭据**：默认弱凭据，防线是不暴露 8333/8888 到公网
- [ ] **Redis 密码**：按需设置 `REDIS_PASSWORD` 并同步后端

## 2. 网络与代理（必配）

- [ ] **`TRUSTED_PROXY_IPS`**：反向代理部署必须配置，否则限流和审计日志记录的是代理 IP
- [ ] **`ALLOWED_HOSTS`**：配置实际域名，防 Host 头注入
- [ ] **`PROD_CORS_ORIGINS`**：填前端实际域名（逗号分隔）
- [ ] **HTTPS**：`HTTPS_REDIRECT=true`（信任 `X-Forwarded-Proto`）；TLS 在 nginx/网关层终结
- [ ] **收敛端口暴露面**：生产封禁 3307/6380/8333/8888，只放行 8010（或 80/443）

## 3. 数据与迁移

- [ ] **迁移脚本随代码提交**：entrypoint 在启动前显式执行
- [ ] **备份**：MySQL 数据在 `docker/volumes/mysql`，日志在 `docker/volumes/logs`
- [ ] **首次启动核对**：`docker logs walnut-backend-go` 应看到迁移成功日志

## 4. 运行参数

- [ ] **`LOGGER_LEVEL`**：prod 推荐 `INFO`
- [ ] **`MAX_FILE_SIZE`**：默认 10MB，按业务需求调整
- [ ] **`PASSWORD_MAX_RETRY_COUNT`**：默认 5 次，`PASSWORD_LOCK_TIME` 默认 10 分钟
- [ ] **`SNOWFLAKE_WORKER_ID`**：多副本部署必须为每实例配不同值（0–1023）

## 5. 监控与告警

- [ ] **健康探针**：`GET /common/health/ready`（DB + Redis 就绪才 200）
- [ ] **存活探针**：`GET /common/health/live`
- [ ] **日志轮转**：lumberjack 默认 100MB/文件、30 份备份、7 天保留
- [ ] **操作日志保留**：`OPERATION_LOG_RETENTION_DAYS=90`（P3 待实现）

## 6. 安全加固

- [ ] **API 文档**：`/docs`、`/redoc` 在白名单内默认公开；生产可在 nginx 层拦截
- [ ] **接口加解密**：确认 `API_DECRYPT_ENABLED=true` 且密钥非默认值
- [ ] **XSS 中间件**：`XSS_ENABLED=true`，`XSS_EXCLUDE_URLS` 排除富文本接口
- [ ] **GZip 中间件**：`GZIP_ENABLED=true`，`GZIP_MIN_SIZE` 默认 1000 字节
