# Go 后端快速开始

本文用于在本机启动 Go 后端并完成第一次接口验证。默认环境为开发环境，生产部署请阅读 `10-Docker部署.md` 和 `11-生产上线清单.md`。

## 1. 前置环境

| 依赖 | 建议版本 | 检查命令 |
|---|---|---|
| Go | 1.26+（`.go-version`） | `go version` |
| MySQL | 8.0+ | `mysql --version` |
| Redis | 7+ | `redis-cli --version` |
| Docker | 24+ | `docker --version` |

项目默认连接 `localhost:3307` 的 MySQL 和 `localhost:6380` 的 Redis。没有本机服务时，先启动公共中间件：

```bash
docker compose -f docker/docker-compose.middleware.yml up -d
```

## 2. Go 环境配置（国内网络必读）

`goproxy.cn` / `goproxy.io` / `sum.golang.google.cn` 在部分网络下会被连接重置。实测可用配方：

```bash
go env -w GOPROXY=https://mirrors.aliyun.com/goproxy/,direct
go env -w GOSUMDB=sum.golang.org
go env -w GOTOOLCHAIN=auto
```

两个反直觉的点：

1. **`GOSUMDB` 保持默认值**。显式改成 `sum.golang.google.cn` 会让 Go 绕过代理直连该主机（被重置）；保持默认时 Go 会把 sumdb 查询经 GOPROXY 转发，阿里云镜像支持这个转发。
2. **不要用 `GOSUMDB=off`**。工具链模块强制要求校验，关掉后连已缓存的工具链都拒绝使用。

> **为什么是 Go 1.26**：`gin v1.12.0` 要求 `go >= 1.25`，`go-redis v9.23.0` 要求 `go >= 1.26`。本机 Go 版本低于此也没关系——`GOTOOLCHAIN=auto` 会经 GOPROXY 自动拉取所需工具链。

## 3. 安装和配置

```bash
cd walnut-backend-go
cp env/.env.example env/.env.dev   # 或直接使用仓库内已提供的 .env.dev
```

按实际环境修改 `env/.env.dev`，至少确认数据库、Redis 和 `SECRET_KEY`。开发环境可以使用仓库示例密钥，生产环境必须替换。

## 4. 启动和验证

```bash
go run . run --env dev
# 或 make dev
```

服务监听 `http://localhost:8011`——与 Python / Java 端相同端口，前端无需任何改动。

数据库 `walnut_seed_go` **不存在时会自动创建**（`databasex.EnsureDatabase` 显式引导）。

验证端点：

- 存活检查：`GET http://127.0.0.1:8011/common/health/check`
- 就绪检查：`GET http://127.0.0.1:8011/common/health/ready`

默认账号 `admin / admin123`。登录接口需要 `clientid` 请求头，完整请求格式见 `04-接口契约.md`。

## 5. 常用命令

```bash
make dev              # 本地启动（go run . run --env dev）
make build            # 编译到 bin/（CGO_ENABLED=0 静态二进制）
make test             # 运行测试
make test-race        # 竞态检测（CI 硬门槛，需 gcc）
make lint             # golangci-lint
make fmt              # gofumpt 格式化
make check            # 提交前完整检查：fmt-check + vet + lint + test-race
make migrate          # 应用迁移
make contract-export  # 从 Python 端导出 golden 契约
make contract-diff    # 双后端响应 diff
make docker-build     # 构建镜像
```

## 6. 启动失败排查

1. **数据库连接失败**：确认 MySQL 已启动、端口为 3307，且 `DATABASE_*` 与实际账号一致。
2. **Redis 连接失败**：确认 Redis 已启动，检查 `REDIS_HOST`、`REDIS_PORT` 和密码。Redis 不可用时应用仍可启动（降级告警），`/common/health/ready` 会返回 503。
3. **依赖拉取超时**：切回阿里云代理（见 §2），`proxy.golang.org` 大文件下载会超时。
4. **路由审计失败**：新接口缺少认证中间件时应用会拒绝启动，应补充 `permguard.Require` 或加入白名单。
