# Go 配置说明

配置加载三级优先级（高 → 低）：真实环境变量 > `env/.env.<ENVIRONMENT>` > 代码默认值。Docker 镜像不包含 `env/`，容器部署应使用 compose 环境变量。

## 配置唯一事实源

`internal/config/config.go` 的 `Config` 结构体定义全部 ~105 项配置，tag 名（`koanf:"KEY"`）与 Python 端 `setting.py` 逐字一致。

## 必须关注的配置

| 变量 | 开发默认值 | 生产要求 |
|---|---|---|
| `ENVIRONMENT` | `dev` | `prod` |
| `SERVER_PORT` | `8011` | 按网关拓扑设置 |
| `SECRET_KEY` | 示例值 | 随机、至少 32 字节，禁止含 `change-me` |
| `DATABASE_HOST/PORT/USER/PASSWORD/NAME` | localhost/3307/root/walnut123/`walnut_seed_go` | 专用账号和库 |
| `REDIS_HOST/PORT/PASSWORD` | localhost/6380/空 | 生产启用密码 |
| `ALLOWED_HOSTS` | `[*]` | 限制为实际域名 |
| `LOGGER_LEVEL` | `DEBUG` | 推荐 `INFO` |

## 安全与接口

- `HTTPS_REDIRECT`：prod 下 HTTP→HTTPS 301 跳转，信任 `X-Forwarded-Proto`
- `TRUSTED_PROXY_IPS`：反向代理部署必须配置，否则限流和审计日志记录的是代理 IP
- `API_DECRYPT_ENABLED`、`API_DECRYPT_PUBLIC_KEY`、`API_DECRYPT_PRIVATE_KEY`：接口加解密；密钥无效时 prod 拒绝启动，dev 自动停用加密并告警
- `CAPTCHA_ENABLE`：验证码开关（math / char 两种模式）
- `PASSWORD_MAX_RETRY_COUNT` / `PASSWORD_LOCK_TIME`：登录失败锁定
- `MAX_FILE_SIZE`：默认 10MB，分块累计计数，超限即中止

启动时 `ensure_bucket` 失败仅告警，首次上传时惰性重试自建。

## 启动期安全校验

`internal/config/validate.go`：

- `SECRET_KEY` 弱值（空 / 含 `change-me` / <32 字节）→ prod 拒绝启动
- RSA 密钥缺失/无效/命中 RuoYi 公开密钥黑名单 → 自动停用接口加解密并告警
- **绝不带假密钥运行**
