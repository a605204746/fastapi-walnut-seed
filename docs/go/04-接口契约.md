# 前后端接口契约

本文是三端（Python / Java / Go）共同遵守的协议。Go 端实现细节在各模块代码注释中。

## 基础约定

- 路由前缀：`/auth`、`/system`、`/monitor`、`/common`、`/resource`
- 成功和业务失败统一返回 `{"code": int, "msg": str, "data": T | null}`
- 分页数据统一 `{"rows": [...], "total": N}`
- 认证请求头：`Authorization: Bearer <token>` 与 `clientid`
- 日期时间格式：`yyyy-MM-dd HH:mm:ss`
- 雪花 ID 超出 JS 安全整数范围时序列化为字符串（`idtype.JSInt`）
- 业务错误使用 HTTP 200 + body.code；路由 404/405 和健康探针 503 使用真实 HTTP 状态码

## 认证和权限

| 端点 | 说明 |
|---|---|
| `POST /auth/login` | 登录 |
| `POST /auth/logout` | 登出（幂等，白名单内） |
| `POST /auth/register` | 注册（受配置开关控制） |
| `GET /auth/code` | 图形验证码 |
| `GET /auth/tenant/list` | 租户下拉 |
| `GET /system/menu/getRouters` | 前端动态路由 |
| `GET /system/user/getInfo` | 当前登录用户信息 |

菜单权限串采用 `模块:实体:操作` 格式（如 `system:user:add`）。前端隐藏按钮不是权限控制，后端必须再次校验。

## 三端实现差异

| 能力 | Python | Java | Go |
|---|---|---|---|
| Web 框架 | FastAPI | Spring Boot | Gin v1.12 |
| ORM | SQLAlchemy 2.x 异步 | MyBatis-Plus | GORM v2 |
| 会话存储 | Redis JSON | Sa-Token/Redis | Redis + JWT |
| 迁移 | Alembic | Flyway | golang-migrate |
| 配置 | `env/.env.*` + pydantic-settings | `application-*.yml` | `env/.env.*` + koanf |
| 日志 | loguru | SLF4J + Logback | slog + lumberjack |
| 对象存储 | minio SDK / oss2 | MinIO Java SDK | minio-go v7 |
| Excel | openpyxl | Apache POI | excelize |

## Golden 契约

Go 端以 `api/openapi/routes.txt` 为 golden 契约（125 条路由，从 Python 端导出），豁免 3 条 docs UI（`/docs`、`/docs/oauth2-redirect`、`/redoc`）。

`test/contract/routes_inventory_test.go` 的 `TestNoInventedRoutes` 是硬门禁：Go 出现 Python 没有的路由 → 测试失败。
