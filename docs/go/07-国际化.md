# 国际化（i18n）

> 更新日期：2026-11-04 · 适用版本：WalnutSeed v1.0

Go 端国际化实现位于 `internal/pkg/i18nx/`，使用 `go:embed` 嵌入 `.properties` 消息文件。

## 1. 机制

### 1.1 语言选择

`internal/pkg/middleware/locale.go`：

1. 解析 `Accept-Language` 请求头
2. 按语言前缀归一化（`zh-TW`→`zh_CN`、`en-GB`→`en_US`）
3. 未知语言回退 `zh_CN`
4. 写入 gin key，下游通过 `middleware.LocaleFrom(c)` 读取

### 1.2 消息解析

`internal/pkg/i18nx/`：

```go
//go:embed messages_zh_CN.properties
var zhCN string

//go:embed messages_en_US.properties
var enUS string
```

`MessageIn(key, locale)` 按 locale 查找对应消息文件，未命中返回键本身。

### 1.3 接入点

`errs.Handler.Resolve` 回调：

```go
app := &App{
    errHandler: &errs.Handler{
        Resolve:  i18nx.MessageIn,     // 消息键解析
        LocaleOf: middleware.LocaleFrom, // 从请求取 locale
    },
}
```

`AuthErrorCode` 的 `MessageKey` 字段（如 `user.password.not.match`）经此回调解析为当前语言的文案。

## 2. 消息文件

`internal/pkg/i18nx/messages_*.properties`，格式与 Python 端 `.properties` 逐字节一致：

```properties
user.password.not.match=用户不存在/密码错误
user.blocked=用户已停用，请联系管理员
repeat.submit.message=不允许重复提交，请稍候再试
```

## 3. 与 Python 端的对齐

- 消息键完全一致（来自同一套 `.properties` 源）
- 语言归一化规则一致
- 回退策略一致（未命中返回键本身）

## 4. 校验错误文案

参数校验错误使用 Pydantic 原文（如 `Field required`、`String should have at most 30 characters`），这是契约的一部分——前端直接展示给用户。`internal/pkg/validatex/` 提供 Pydantic 文案映射。
